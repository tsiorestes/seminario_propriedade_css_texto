3 - Decoração de texto CSS

A propriedade CSS é usada para controlar a aparência de linhas decorativas no texto. text-decoration

É uma abreviação para as seguintes propriedades individuais:

  1. text-decoration-line
  2. text-decoration-color
  3. text-decoration-style
  4. text-decoration-thickness

3.1 text-decoration-line

A propriedade CSS define o tipo de linha de decoração adicionada ao texto. text-decoration-line

Esta propriedade pode ter um ou mais dos seguintes valores:

Esta propriedade é usada para definir o tipo de decoração de texto. Os valores possíveis são:

  • none - Valor padrão. Não exibe nenhuma linha de decoração.
  • underline - A linha de decoração é exibida abaixo do texto.
  • overline - A linha decorativa é exibida sobre o texto.
  • line-through - A linha de decoração é exibida através do texto.

3.1.1 text-decoration-line: none

Nenhuma linha decorativa


3.1.2 text-decoration-line: underline

Exibe uma linha decorativa abaixo do texto.


3.1.3 text-decoration-line: overline

Exibe uma linha decorativa acima do texto.


3.1.4 text-decoration-line: line-through

Exibe uma linha decorativa através do texto.

3.1.5 text-decoration-line: underline overline

Exibe uma linha decorativa acima e abaixo do texto.


3.2 text-decoration-color

A propriedade CSS é usada para definir a cor da linha decorativa. text-decoration-color

Essa propriedade pode ter um dos seguintes valores:

  • color - Define a cor da linha decorativa. Pode ser especificada por nome, valor hexadecimal ou valor RGB.
  • text-decoration-color: inherit - A linha decorativa herda a cor do elemento pai.

  • .underlineoverlinineyellow{ text-decoration-line: underline overline; text-decoration-color: yellow red; }- Define a cor amarela para a linha decorativa.

3.3 text-decoration-style

A propriedade CSS é usada para definir o estilo da linha decorativa. text-decoration-style

Essa propriedade pode ter um dos seguintes valores:

  • solid - Linha contínua.
  • dotted - Linha pontilhada.
  • dashed - Linha tracejada.
  • wavy - Linha ondulada.
  • double - Linha dupla.

3.3.1 text-decoration-style: solid

Linha contínua.

.line_solid{ text-decoration-line: underline; text-decoration-style: solid; }


3.3.2 text-decoration-style: dotted

Linha pontilhada.

.line_dotted_blue{ text-decoration-line: underline; text-decoration-style: dotted; text-decoration-color: blue; }


3.3.3 text-decoration-style: dashed

>Linha tracejada.

.line_dashed{ text-decoration-line: underline; text-decoration-style: dashed; }


3.3.4 text-decoration-style: wavy

Linha ondulada.

.line_wavy{ text-decoration-line: underline; text-decoration-style: wavy; }


3.3.5 text-decoration-style: double

Linha dupla.

.line_double_red{ text-decoration-line: underline; text-decoration-style: double; text-decoration-color: red; }

A propriedade CSS é usada para definir a espessura da linha decorativa.

3.4.1 text-decoration-thickness: Xpx

Define a espessura da linha decorativa como 2 pixels.

.line_thickness{ text-decoration-line: underline; text-decoration-thickness: 2px; }

3.4.2 text-decoration-thickness: auto

A propriedade text-decoration-thickness: auto define que a espessura da linha decorativa será escolhida automaticamente pelo navegador.

Esse é o valor padrão (default) da propriedade se você não especificar nenhum outro.

Como o navegador calcula o auto?

  • Baseado na fonte: O navegador analisa a fonte que está sendo usada (font-family) e o tamanho dela (font-size).
  • Design da tipografia: Muitas fontes modernas possuem metadados embutidos que sugerem ao navegador a espessura ideal e a posição para o sublinhado, garantindo que o traço combine com o peso visual das letras.
  • Proporcionalidade: Se você aumentar o tamanho do texto, o navegador aumentará a espessura da linha automaticamente para que ela não fique fina ou grossa demais.

Define a espessura da linha decorativa como automática.

.line_thickness{ text-decoration-line: underline; text-decoration-thickness: auto; }


3.4.3 text-decoration-thickness: from-font

Define a espessura da linha decorativa com base na fonte utilizada.

Exemplo 01: .line_thickness{ text-decoration-line: underline; text-decoration-thickness: from-font; }

Exemplo 02: .line_thickness{ text-decoration-line: underline; text-decoration-thickness: from-font; }


3.4.4 text-decoration-thickness: 0.1em

Define a espessura da linha decorativa como 0.1em.

O que significa 0.1em: A unidade em é relativa ao tamanho da fonte (font-size) do próprio elemento. Portanto, 0.1em significa que a linha terá uma espessura equivalente a 10% do tamanho da letra atual (por exemplo, se o texto tem font-size: 20px, a linha terá 2px de espessura).

.line_thickness{ text-decoration-line: underline; text-decoration-thickness: 0.1em; }


Define a espessura da linha decorativa como 0.5em.

O que significa 0.5em: A unidade em é relativa ao tamanho da fonte (font-size) do próprio elemento. Portanto, 0.5em significa que a linha terá uma espessura equivalente a 50% do tamanho da letra atual (por exemplo, se o texto tem font-size: 20px, a linha terá 10px de espessura).

.line_thickness{ text-decoration-line: underline; text-decoration-thickness: 0.1em; }
