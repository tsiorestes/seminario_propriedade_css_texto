Alinhamento e direção do texto em CSS

Neste capítulo você aprenderá sobre as seguintes propriedades:

  1. text-align
  2. text-align-last
  3. vertical-align
  4. direction
  5. unicode-bidi

2.1 Text-alignment - Alinhamento de texto

Essa propriedade text-align é usada para definir o alinhamento horizontal de um texto.

Essa propriedade pode ter um dos seguintes valores:

  1. left
  2. right
  3. center
  4. justify

2.1.1 left

Alinha o texto à esquerda >> text-align: left

2.1.2 right

Alinha o texto à direita >> text-align: right

2.1.3 center

Centraliza o texto >> text-align: center

2.1.4 justify

O efeito de "esticar" (justificar) só acontece visualmente quando o texto é longo o suficiente para quebrar em duas ou mais linhas. O navegador espalha as palavras das linhas de cima para que as margens esquerda e direita fiquem retas, mas deixa a última linha alinhada à esquerda. >> text-align: justify

2.2 Propriedade CSS text-align-last

Essa propriedade text-align-last é usada para definir o alinhamento da última linha de um texto.

  1. auto- Valor padrão. A última linha é justificada e alinhada à esquerda.
  2. left- A última linha está alinhada à esquerda;
  3. right- A última linha está alinhada à direita;
  4. center- A última linha está alinhada ao centro;
  5. justify- A última linha está justificada, assim como as demais;
  6. start- A última linha está alinhada com o início da linha;
  7. end- A última linha está alinhada com a extremidade da linha.

A última linha é justificada e alinhada à esquerda. >> text-align-last: auto

2.3 Alinhamento vertical

Essa vertical-align propriedade define o alinhamento vertical de um elemento.

Essa propriedade pode ter um dos seguintes valores:

  1. baseline - Valor padrão. O elemento está alinhado com a linha de base do elemento pai.
  2. length/% - Eleva ou abaixa um elemento pelo comprimento ou porcentagem especificados
  3. sub - O elemento está alinhado com a linha de base do subscrito do elemento pai.
  4. super - O elemento está alinhado com a linha de base do sobrescrito do elemento pai.
  5. top - O elemento está alinhado com o topo do elemento mais alto da linha.
  6. text-top - O elemento está alinhado com a parte superior da fonte do elemento pai.
  7. middle - O elemento é posicionado no meio do elemento pai.
  8. bottom - O elemento está alinhado com o elemento mais baixo da linha.
  9. text-bottom - O elemento está alinhado com a parte inferior da fonte do elemento pai.

2.4 Propriedade CSS direction

Essa propriedade direction é usada para definir a direção do texto.

  1. ltr - Valor padrão. O texto é exibido da esquerda para a direita.
  2. rtl - O texto é exibido da direita para a esquerda.

2.5 Propriedade CSS unicode-bidi

Essa propriedade unicode-bidi é usada para definir o comportamento do texto bidirecional.

  • normal - Valor padrão. O texto é exibido normalmente.
  • embed - O texto é exibido de acordo com a direção do elemento pai.
  • bidi-override - O texto é exibido de acordo com a direção do elemento pai, mas os caracteres são exibidos na ordem inversa.
