7 SHADOW TEXT/ TEXTO DE SOMBRA

Como o nome sugere, esse efeito adicionaria uma sombra a uma frase.

7.1 Como vocês podem ver neste exemplo aqui

Não so isso, como você tambem teria o controle de o seu tamanho vertical e o horizontal,
e mudar sua cor como adicionar um desfoque para embelezar o seu texto.

este seria o codigo utilizado no CSS para fazer tais detalhes. Vamos criar um exemplo de um codigo desses aqui.
#Qualquer_Sombra_Que_Queira { text-shadow: 5px 5px 5px pink; }
O primeiro Px diz o valor do alinhamento horizontal da sombra, positivos vão a direita e os negativos vão a esquerda.
O segundo Px diz o valor do alinhamento vertical da sombra, positivos vão para baixo e enquanto os negativos vão para cima.
O terceiro Px dita o quão desfocado estara a sombra.
E o Pink diz qual sera a cor da sombra. quando não é colocado a sombra sempre sera preta.

7.2.1 Multiplas Sombras

é possivel tambem configurar para que varias sombras pertenção ao mesmo texto.
é bem simples isso. é so separar as variaveis de diferentes sombras dentro do mesmo algoritimo com uma virgula, como neste exemplo
#exemplo { text-shadow: 0 0 3px #ff0000, 0 0 5px #0000ff; }
