6.1 Text Indentation

Esta CSS serveria para dar um recuo na primeira linha ao texto.
E esta seria o seu aloritimo #recuo {text-indent: 50px;} Caso o seu valor px seja negativo, o recuo ira para a esquerda
você pode colocar o valor em % ou em Cm caso lide melhor com diferentes definiçoes numericas.

6.5 White Space

Esta propriedade de CSS espexifica o expaço em branco é usado. principalmente dentro de um


Existem 5 valores dentro desta propriedado.
O normal, no qual não altera em nada.
O nowrap no qual otexto não vai se enrolar na caixa por si só. ele vai precisar de uma tag br para dar uma linha.
pre o texto branco é preservado pelo brownser, o texto so vai dar linhas em quebra linhas, ele funciona da mesma maneira que atag pre do HTML.
pre-line A sequencia de espaço em branco vai se amontuar em um unico espaço em branco, o texto vai dar uma volta quando necessario, e com quebra de linhas.
pre-wrapO expaçamento em branco vai ser preservado pelo brownser, o texto so vai se virar quando necessario. e numa quebra de linhas.
