5.1 TEXT TRANSFORMATION/ TRANSFORMAÇÃO DE TEXTO

Este codigo seria usador para modificar a capitalização das letras, se elas estão minusculas ou maiusculas, muito util caso não queira modificar o html da pagina.

  1. none
  2. capitalize
  3. uppercase
  4. lowercase

5.1 text-transform: None

Bem nada aconteceria. O texto ficaria completamente igual.

5.2 text-transform: Capitalize

Como o nome indica, capitaliza a frase. Para ser mais exato, a primeira letra de cada palavra da frase.

lorem ipsum dolor, sit amet consectetur adipisicing elit. Necessitatibus asperiores ipsum laboriosam

5.3 text-transform: Uppercase

Siginifica "Maiusculo". Este codigo capitalizaria todas as letras da frase.

lorem ipsum dolor sit, amet consectetur adipisicing elit. Ipsum quidem possimus non fugit distinctio id

5.4 text-transform: Lowercase

Siginifica "Minusculo". Este diminuiria todas as letras da frase.

lorem ipsum dolor sit amet, consectetur adipisicing elit. Esse illum iusto, repudiandae assumenda
