1 - Text Color - Configurado pela classe para ser cor vermelha. h1 { color: red;}

Essa colorpropriedade é usada para definir a cor do texto. A cor é especificada por:

1.1 Cores pré-definidas por nome.

O nome define a cor pelo seu nome - como "color: red;"

1.2 Cores especificadas por valor HEXADECIMAL

Códigos Hexadecimais (Hex): Representam valores RGB em formato hexadecimal. É o método mais popular na web. Pode ser usado com 6 caracteres (#FF5733) ou de forma curta com 3 (#F53). Também aceita 8 caracteres para incluir transparência como "color: #ff0000;"

1.3 Cores especificadas por valor RGB

Funções RGB / RGBA: Definem a cor misturando Vermelho (Red), Verde (Green) e Azul (Blue) com valores de 0 a 255. Esse texto usou um valor RGB - como "color: rgb(255,0,0)"
